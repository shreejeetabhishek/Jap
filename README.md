# Divya Jap — fresh offline-first source

This is a fresh implementation using only three source files:
- `index.html`
- `styles.css`
- `app.js`

No external libraries, CDN scripts, remote images, web fonts, 3D engines or network requests are used.

## Run
Open `index.html` in a modern browser, or publish the three files in the root of a static hosting repository.

## Included
- Hanging single-strand mala with Guru bead and tassel
- Procedural Rudraksha-style bead drawing with irregular silhouette, five deep winding Mukhi channels, raised texture marks and central thread bore
- Tulsi, Sphatik and Chandan material appearances
- Tap/swipe counting, target selection, progress, malas/total counters
- Chant picker and custom chant
- Sound toggle, light/dark theme, reset
- LocalStorage persistence

## Visual note
The bead is drawn procedurally with Canvas 2D. It simulates depth and surface relief; it is not a scanned or physically modelled 3D seed. The exact appearance depends on screen size and browser rendering.
